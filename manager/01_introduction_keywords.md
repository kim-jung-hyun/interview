## 1) 자기소개·경력

- LG전자 단말기 SW → Integration → Production Release → SW Project Leader → (현재) 차세대연구소 **Security PM**

- 현재 업무 ① **선행 보안기술** — 보안개발팀 + 사업부 SW/HW + 상품기획 + 마케팅 조율
- 현재 업무 ② **보안기술 인증체계** — Requirement·Verification → Evidence 기반 Assessment 구조
- 최근 확장: **AI/Agent Security, AI Governance**
  - 정책 코드화 + Evidence 검증 구조
  - 특허 — 정책·위협 시그널·테스트 동기화
