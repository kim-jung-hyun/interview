# rendered/ — 표가 표로 보이는 파일

`.md` 원본을 편집기에서 보면 표가 **파이프 문자로만** 보인다. 이 폴더는 그걸 렌더한 결과다.

## 무엇을 열면 되나

| 파일 | 용도 |
|---|---|
| **`ALL.html`** | **전체 8개 문서 + 그림 5장이 한 파일.** 브라우저로 열면 목차·표·그림이 다 보인다. **이것만 열면 된다** |
| `ALL.docx` | 같은 내용의 Word 파일. HWP로 옮기거나 편집할 때 |
| `00_note.html` 등 개별 파일 | 문서 하나만 볼 때 |
| `00_note.docx` 등 개별 파일 | 문서 하나만 Word로 |

**`ALL.html`은 그림이 파일 안에 박혀 있다**(self-contained). USB로 옮겨도 그림이 깨지지 않는다.

## 인쇄

`ALL.html`을 브라우저에서 열고 **Ctrl+P**. 인쇄용 CSS가 들어 있어서

- 문서마다 새 페이지에서 시작
- 표·그림이 페이지 중간에서 잘리지 않음
- 본문 11pt, 표 9.5pt

Plan B용 출력물은 이걸 쓰면 된다.

## 원본이 바뀌면 다시 만든다

`.md`가 정본이고 이 폴더는 **파생물**이다. 원본을 고친 뒤 다시 돌린다.

```bash
cd interview/rendered
./build.sh
```
